# How to Export Filtered and Grouped Data from WPF SfDataGrid

## Overview

This example demonstrates how to export filtered and grouped data from a Syncfusion WPF DataGrid (`SfDataGrid`) control. The sample project showcases best practices for exporting data while preserving filter and grouping states.

## About Syncfusion WPF DataGrid

The Syncfusion WPF DataGrid (`SfDataGrid`) is a powerful data visualization control that provides:

- **High-performance data binding** for large datasets
- **Advanced filtering and sorting capabilities** to organize data efficiently
- **Grouping functionality** to logically organize and summarize data
- **Flexible export options** including Excel, PDF, and CSV formats
- **Customizable appearance and behavior** with templates and styling support
- **Interactive features** like selection, editing, and data validation

## Key Features in This Example

- Export filtered data while maintaining filter conditions
- Export grouped data with proper hierarchy preservation
- Export selected records from the DataGrid
- Customize export format and appearance
- Handle large datasets efficiently during export

## Technology Stack

- **Framework**: .NET Framework / .NET Core
- **Language**: C#
- **UI Framework**: WPF (Windows Presentation Foundation)
- **Component**: Syncfusion DataGrid for WPF

## Getting Started

1. Clone or download this repository
2. Open the solution in Visual Studio
3. Restore NuGet packages (Syncfusion dependencies)
4. Build and run the application
5. Interact with the DataGrid (apply filters, create groups)
6. Use the export functionality to export the current view state

## Use Cases

- Export filtered records for reporting
- Generate grouped summaries for analysis
- Export selected data for team collaboration
- Archive filtered datasets in various formats
- Create custom reports with grouped information

## Requirements

- Visual Studio 2017 or higher
- .NET Framework 4.6.2 or higher (or .NET Core 3.1+)
- Syncfusion WPF components (included via NuGet)
